# Website

Personal site for Rajarshi Chattopadhyay, published at [likarajo.github.io](https://likarajo.github.io).

* Site: [Astro](https://astro.build/)
* Interactive pieces: [React (JSX)](https://react.dev/)
* Components: [Material UI](https://mui.com/)
* Host: [GitHub Pages](https://docs.github.com/pages), from the `gh-pages` branch

Astro uses Vite to build the site. The commands below are Astro commands.

## Develop

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:4321.
